# Menina Mimada Acessórios — site estático

Sem build. Arquivos: `index.html`, `assets/` (fotos), `vercel.json` (cabeçalhos de segurança).

## Configuração (um único local)
No `index.html`, procure `const CONFIG`:
- `whatsapp`: só dígitos com DDI. Valor atual `553192723847` — CONFIRMAR com a loja (celulares de MG têm 9 dígitos após o DDD; pode faltar o 9).
- `instagram`: `@meninamimada_acessorios`.

## Catálogo (const P)
`name`, `price` e `desc` estão vazios e só aparecem na tela quando preenchidos. Os títulos atuais são descrições visuais das fotos.

## Pendências
- Nomes, preços, materiais e descrições reais das peças.
- Confirmar categorias (deduzidas pelas fotos).
- Fotos originais em alta resolução (as atuais são capturas de tela do Instagram) e logo oficial.
- Política de privacidade/troca: só publicar se a loja fornecer.
- Não há coleta de dados, backend ou rastreadores.
